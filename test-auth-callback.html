Note: These are test URLs with fake tokens. In development, they will show error pages, but you should see detailed debugging information in:
  • Browser developer console
  • Your Next.js server console
  • The error page itself (in development mode)

Expected Results

✅ PKCE Flow: Should show "Code exchange failed" (expected with test token)
✅ Token Flow: Should show "Token session failed" (expected with test token)
✅ Legacy Flow: Should redirect to /auth/confirm
✅ Fragment Flow: Should show "Token session failed" (expected with test token)
✅ Empty Params: Should show detailed error with "No parameters found in URL"
✅ Malformed: Should show detailed error with "Available parameters: invalid, random"
